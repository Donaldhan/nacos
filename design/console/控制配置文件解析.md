## 📋 配置参数详解

### 🌐 **Spring Boot 相关配置** (第17-23行)

```properties
server.servlet.contextPath=/nacos
```
- **作用**：设置 Web 应用的上下文路径，访问 Nacos 控制台需要在 URL 后加 `/nacos`

```properties
server.error.include-message=ALWAYS
```
- **作用**：错误响应中始终包含错误信息字段

```properties
server.port=8848
```
- **作用**：Nacos 服务器端口，默认 8848

---

### 🌍 **网络相关配置** (第25-30行)

```properties
# nacos.inetutils.prefer-hostname-over-ip=false
```
- **作用**：集群配置中是否优先使用主机名而不是 IP 地址

```properties
# nacos.inetutils.ip-address=
```
- **作用**：指定本机服务器的 IP 地址（多网卡时使用）

### ⚙️ **配置模块相关** (第32-46行)

```properties
# spring.sql.init.platform=mysql
# db.num=1
# db.url.0=jdbc:mysql://127.0.0.1:3306/nacos?...
# db.user=nacos
# db.password=nacos
```
- **作用**：外部数据库（MySQL）配置，默认使用内嵌 Derby 数据库
- `db.num`：数据库实例数量
- `db.url.0`：第一个数据库连接 URL
- `db.user/db.password`：数据库账号密码

```properties
nacos.config.push.maxRetryTime=50
```
- **作用**：配置推送失败时的最大重试次数

---

### 🏥 **服务发现模块相关** (第48-59行)

```properties
# nacos.naming.data.warmup=true
```
- **作用**：是否启用数据预热，false 表示服务启动未准备好时就接受请求

```properties
# nacos.naming.expireInstance=true
```
- **作用**：是否启用实例自动过期（类似健康检查）

```properties
nacos.naming.empty-service.auto-clean=true
nacos.naming.empty-service.clean.initial-delay-ms=50000
nacos.naming.empty-service.clean.period-time-ms=30000
```
- **作用**：空服务自动清理
    - `auto-clean`：是否自动清理没有实例的服务
    - `initial-delay-ms`：首次清理延迟时间（50秒）
    - `period-time-ms`：清理周期（30秒）

### 📝 **访问日志相关** (第92-103行)

```properties
server.tomcat.accesslog.enabled=true
```
- **作用**：是否启用 Tomcat 访问日志

```properties
server.tomcat.accesslog.max-days=30
```
- **作用**：访问日志自动清理的天数（保留30天）

```properties
server.tomcat.accesslog.pattern=%h %l %u %t "%r" %s %b %D %{User-Agent}i %{Request-Source}i
```
- **作用**：访问日志格式
    - `%h`：远程主机
    - `%t`：时间
    - `%r`：请求行
    - `%s`：状态码
    - `%D`：处理时间（毫秒）


- **作用**：访问日志存储目录

### 🔐 **访问控制相关** (第106-145行)

```properties

```


## ⚠️ **重要安全建议**

1. **生产环境必须配置**：
    - `nacos.core.auth.enabled=true`（开启认证）
    - `nacos.core.auth.plugin.nacos.token.secret.key`（设置强密钥）
    - 使用外部 MySQL 数据库并配置强密码

2. **可选优化**：
    - 启用 TLS 加密通信
    - 配置 LDAP 统一认证
    - 启用 Webhook 配置变更通知
