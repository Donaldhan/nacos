### 步骤 2：配置 Token 密钥

#### 方案 A：使用简单密钥（仅测试环境）

在第 163 行添加：
```properties
nacos.core.auth.plugin.nacos.token.secret.key=SecretKey012345678901234567890123456789012345678901234567890123456789
```

#### 方案 B：生成强密钥（推荐生产环境）

**方法 1：使用 OpenSSL**
```bash
# 生成随机密钥
openssl rand -base64 48

# 输出示例：
# K7gnuM3vFJ8xQ2wL9pR5tY1hB4nD6cA0eG2iS8uW3zX5bV7mN9qP1rT4yH6j
```

**方法 2：使用 Python**
```bash
python3 -c "import secrets; import base64; print(base64.b64encode(secrets.token_bytes(48)).decode())"

# 输出示例：
# 8xK2mN5pQ9rT3yV6wZ1bD4fH7jL0nR2sU5vX8aB3cE6gI9kM1oP4qS7uW0y
```

**方法 3：使用 Java**
```bash
cat > /tmp/GenKey.java << 'EOF'
import java.util.Base64;
import java.security.SecureRandom;

public class GenKey {
    public static void main(String[] args) {
        byte[] randomBytes = new byte[48];
        new SecureRandom().nextBytes(randomBytes);
        String secretKey = Base64.getUrlEncoder().withoutPadding().encodeToString(randomBytes);
        System.out.println(secretKey);
    }
}
EOF

javac /tmp/GenKey.java
java -cp /tmp GenKey

# 输出示例：
# Lm9X2kP5nR8qT1yV4wZ7bD0fH3jL6nR9sU2vX5aB8cE1gI4kM7oP0qS3uW6y
```

将生成的密钥配置到第 163 行：
```properties
nacos.core.auth.plugin.nacos.token.secret.key=<你生成的密钥>
```

#### 可选：配置 Token 过期时间（第 161 行）

```properties
# 默认 18000 秒（5小时），可根据需要调整
nacos.core.auth.plugin.nacos.token.expire.seconds=18000
```

### 步骤 2：客户端代码中添加认证配置

#### 场景 A：Java SDK 客户端

**Maven 依赖**：
```xml
<dependency>
    <groupId>com.alibaba.nacos</groupId>
    <artifactId>nacos-client</artifactId>
    <version>2.5.1</version>
</dependency>
```

**配置中心示例**：
```java
import com.alibaba.nacos.api.NacosFactory;
import com.alibaba.nacos.api.config.ConfigService;
import com.alibaba.nacos.api.exception.NacosException;
import java.util.Properties;

public class NacosConfigExample {
    public static void main(String[] args) throws NacosException {
        Properties properties = new Properties();
        
        // 服务器地址
        properties.setProperty("serverAddr", "localhost:8848");
        
        // 命名空间（可选）
        properties.setProperty("namespace", "your-namespace-id");
        
        // 🔑 认证信息（必须添加）
        properties.setProperty("username", "nacos");
        properties.setProperty("password", "nacos");  // 首次登录后请修改密码
        
        // 创建配置服务
        ConfigService configService = NacosFactory.createConfigService(properties);
        
        // 获取配置
        String dataId = "example-config";
        String group = "DEFAULT_GROUP";
        long timeoutMs = 5000;
        
        String content = configService.getConfig(dataId, group, timeoutMs);
        System.out.println("Config content: " + content);
        
        // 监听配置变化
        configService.addListener(dataId, group, new Listener() {
            @Override
            public void receiveConfigInfo(String configInfo) {
                System.out.println("Config changed: " + configInfo);
            }
            
            @Override
            public Executor getExecutor() {
                return null;
            }
        });
    }
}
```

**服务发现示例**：

4. ✅ 查看服务器日志：`tail -f logs/auth.log`

## 六、安全加固建议

1. **修改默认密码**
   ```bash
   # 登录控制台后，访问：系统管理 -> 用户列表 -> 修改密码
   ```

2. **启用 HTTPS**
   ```properties
   # application.properties
   server.ssl.enabled=true
   server.ssl.port=8443
   server.ssl.key-store=classpath:keystore.p12
   server.ssl.key-store-password=your-password
   server.ssl.key-store-type=PKCS12
   server.ssl.key-alias=tomcat
   ```

3. **限制访问 IP**
   ```properties
   # 在 nacos.security.ignore.urls 中添加需要排除的 IP
   nacos.security.ignore.urls=/,/error,/**/*.css,/**/*.js,/**/*.html,/**/*.map,/**/*.svg,/**/*.png,/**/*.ico,/console-ui/public/**,/v1/auth/**,/v1/console/health/**,/actuator/**,/v1/console/server/**
   ```

4. **定期轮换密钥**
   ```bash
   # 建议每 3-6 个月更换一次 token.secret.key
   # 更换后需要重启所有节点和客户端
   ```

5. **审计日志**
   ```bash
   # 开启详细日志
   vim conf/nacos-logback.xml
   
   # 添加 auth 模块的日志配置
   <logger name="com.alibaba.nacos.auth" level="DEBUG"/>
   ```
